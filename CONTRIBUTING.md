# Contributing to ORBIT

Thanks for helping build ORBIT.

## Workflow
1. Read `README.md` and the documents in `Documentation/`.
2. Discuss larger design changes in the [Collaboration Board](https://github.com/atlaswalker1234567890-spec/ORBIT/issues/1).
3. Make focused changes on a feature branch.
4. Explain how changes were tested; clearly mark untested code.
5. Open a pull request for review.

## Working with multiple assistants
ChatGPT, Claude, and human contributors can coordinate through the GitHub Collaboration Board. Share the repository and board links with each assistant. They do not automatically share conversation history or private context, so put durable decisions and handoffs in the repository.

## Code expectations
- Keep modules small and loosely coupled.
- Avoid committing generated Unity folders and build outputs.
- Never commit credentials, tokens, private keys, or personal connection profiles.
- Do not claim device compatibility without testing on the named hardware.
