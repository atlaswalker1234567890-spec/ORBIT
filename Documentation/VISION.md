# ORBIT — Product Vision

## One-line vision

A customizable virtual computing universe that lets people shape their workspace, connect to the computers they use, and choose the world in which they work.

## The promise

**Your computer. Your operating system. Your workspace. Your universe.**

ORBIT should feel less like a single remote-desktop app and more like a personal computing space. The user decides what screens exist, where they sit, what the room looks like, which devices are present, and which computing workflows are available.

## Experience pillars

### 1. A spatial desktop
- Multiple virtual displays and windows.
- Adjustable screen size, resolution, curvature, distance, and position.
- Saved layouts for different tasks.
- Comfortable text rendering and reliable input.

### 2. Connect to real computers
- A companion application for desktop capture and streaming.
- Remote keyboard, mouse, and controller input.
- Investigate SSH, RDP, VNC, and WebRTC-based approaches where appropriate.
- Clear connection state, permissions, and quality controls.

### 3. Linux and developer workflows
- A useful terminal and shell experience.
- SSH, editors, file browsing, and developer tools.
- Explore local Linux userspace options on Quest where platform constraints permit.
- Support remote graphical Linux desktops as a practical route to a complete desktop experience.
- Treat full local virtual-machine support as an unproven research item, not a promise.

### 4. Make the space yours
- Desks, chairs, computers, cases, monitors, keyboards, and peripherals.
- Hardware-inspired themes: retro workstations, CRT setups, server rooms, modern gaming rigs, and minimalist studios.
- Lighting, fans, RGB effects, and ambient details.
- Save, import, export, and share configurations over time.

### 5. Worlds and atmosphere
- Built-in and downloadable environments.
- Natural, abstract, sci-fi, historical, and user-created spaces.
- Time of day, lighting, weather, animation, and ambient sound controls.
- An option to keep environments visually quiet for focused work.

## Product principles

- **Comfort over spectacle:** avoid visual clutter and motion that makes long sessions unpleasant.
- **Fast path to work:** users should be able to enter a useful workspace quickly.
- **Customization without fragility:** defaults should work; advanced settings should remain optional.
- **Interoperability:** prefer documented protocols and portable formats.
- **Security by design:** never expose remote access or credentials without clear user intent.
- **Incremental delivery:** prove the core workspace before expanding into an ecosystem.

## What ORBIT is not (initially)

- Not a replacement for every desktop operating system.
- Not a guarantee that arbitrary desktop Linux distributions can run natively on Quest.
- Not a game-streaming service; streaming from a user's own computer is the initial direction.
- Not a marketplace until the core application and content pipeline are stable.

## First success criteria

A user can launch ORBIT, arrange a few readable virtual screens, connect to a computer reliably, interact with it comfortably, and return to a saved workspace without fighting the interface.
